# Blend Tree map asset

Generated from the user-approved Blend Tree v01. Map reduction: 22,699 triangles, 878,648 bytes, 16 mesh groups. Self-contained materials and vertex colors; cyan emissive pods. No external textures or decoder required.

Source model and rebuild scripts: artifacts/blend-tree-v01 in the workspace. Run build_tree.py, export_web.py, then export_map.py with Blender 5.2. The map scales the source to 0.35 of its original height before applying per-tile variation.

Geometry authored for this project from the supplied reference image. Static scenery; no wind animation. Mesh/material resources are shared across copies.
